## Delivery measurements and recommendation

The 54-plan ciphertext is 1,065,947 bytes; public hash/placement manifest 1,136,659 bytes. Original plan hashes prove preservation. Build-process memory is recorded separately and is not hosted function memory.

Initial authenticated measurement covered 55 requests across 11 lessons. The ten new lessons produced 10,513–12,801 decoded bytes, median 763 ms across their 50 requests (range 484–1,135 ms) through the coding proxy while other verification ran. A separate sequential final run made 15 requests across three representative lessons: median 1,000 ms; subsequent per-lesson medians 929.5, 939.5 and 973 ms. First observed samples are not guaranteed cold. All responses remain private/no-store. These different conditions do not establish a causal slowdown versus earlier batches.

Browser heap during full navigation/PDF generation ranged approximately 10.33–94.31 MiB; this is not hosted server RSS or evidence of a leak. Each selected-plan request still decrypts/validates the whole release; no plaintext cache is introduced. Current observations do not establish 395-plan suitability. Measure decryption/validation, guaranteed cold processes and concurrent server memory before selecting smaller authenticated lesson/term releases, versioned manifests or a server cache. Retain fresh authorisation for every response. Architecture changes and migrations require separate approval.
