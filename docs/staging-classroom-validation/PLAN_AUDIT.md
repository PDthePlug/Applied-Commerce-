# Review of the existing 24 plans

Review basis: published PR #44, complete authorised API payloads retrieved by genuine educator password login on 23 October 2026, and the corresponding actual learner runtime lessons. The abandoned milestone was not consulted. This is an instructional desk review, not independent teacher moderation or a classroom trial. Hash/field checks establish preservation, not educational quality.

The workbook already explains most concepts adequately. Keep preparation, explanations, examples, misconceptions and understanding indicators. The recurring weakness is compulsory-looking Explain/Ask/Task/Check groups and additional written/paired tasks at almost every stage. These compete with reading and existing responses. The implementation uses the existing short introduction/instruction as the main cue, retains all original fields in the adjacent optional disclosure, and treats extra prompts as support rather than new work. No canonical source, field, outcome or saved-work identity is changed. Personal reflection remains available; fictional modelling is an alternative where appropriate.

Across the plans, original checkpoints provide the primary understanding evidence. Teachers can sample a reason, clarify an error and let learners continue. Filled fields, optimism, public confidence or promised behaviour do not establish understanding. Later observations, interviews, week-long practice and portfolio exhibitions remain later work. All 24 plans retain their full private printable/standalone representation.

Residual limits: changing layout does not revise the original wording of optional support. Some support still phrases supplementary tasks as imperatives; its optional status is explicit in the local panel. The G8 L12 reference to a methods table remains in encrypted guidance and is registered for a future private-content wording release. Current timings remain planning envelopes rather than measured minute-by-minute prescriptions.
