The five guides are authored enrichment drafts, with agent self-review and automated checks. Independent South African educator approval and classroom pilots have **not** occurred. The other 390 lessons have a source-based screen and provisional planning requirements, not completed teaching plans or a claim of full educational moderation.

Teacher notes, indicative reasoning, PDFs and screenshots containing those notes must remain private. The repository is public, so the guide release is encrypted and the key is held separately. A public GitHub preview cannot serve the notes until an authorised operator provisions that private release key. No database migration, production deployment or Supabase test writes form part of this milestone.
